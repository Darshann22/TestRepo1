TestRepo1
========

Tiny front-end demo for experimenting with DOM interactions and simple JavaScript.

Files
- `index.html` — page
- `script.js` — behavior

Quick start
- Serve locally: `python3 -m http.server 8000` and open http://localhost:8000
- Or open `index.html` directly in a browser

Tip
- Add a `toggleBtn` and a `content` area; in `script.js` toggle visibility and update the button label.

Contribute
- Create a branch, commit changes, and open a PR against `main`.
